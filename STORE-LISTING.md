Suggested description addition for version 1.1.0:

Enable the optional quick popup to search selected text using clickable website icons. Choose its light or dark appearance, position around your selection, and which websites appear. The right-click search menu remains available.

SEARCHIT is open source under the MIT license. Review the code, contribute, or download it for manual installation: https://github.com/hgurb/SEARCHIT---Right-Click-Search

Additional permission explanations for the Chrome Web Store:

scripting: Registers the optional quick-popup content script on permitted webpages so it can detect selected text and display clickable search icons. The script is packaged with the extension.

Optional HTTP/HTTPS website access: Requested when the user enables the quick popup. Allows the popup to appear beside selected text on ordinary webpages. Selected text is processed locally and sent to a destination website only when the user clicks a search action.
